# Перевод вкладки · v0.5.0

[English](RELEASE_NOTES.md) | **Русский**

Первая публичная версия: озвучка и субтитры звука выбранной вкладки через личный ключ Gemini API.

- Режимы «Озвучка», «Субтитры» и «Оба».
- Автоматическое определение языка оригинала; выбор языка перевода по Chrome или вручную.
- Короткий список основных языков и поиск по полному списку из 78 вариантов.
- Интерфейс на 12 языках; для остальных целей перевода интерфейс английский.
- Настройки подключения внутри окна расширения и встроенная инструкция по ключу.
- Локальная история текста за 7 дней, поиск, копирование и удаление записей.
- Собственный движок соединения и обработки PCM; код распространяется под 0BSD.

## Установка

Скачайте `tab-audio-translator-v0.5.0.zip`, распакуйте и загрузите папку с `manifest.json` через `chrome://extensions` → «Режим разработчика» → «Загрузить распакованное расширение».

Для запуска нужен собственный ключ Gemini API и доступ к модели. Использование Google API зависит от квот и тарифа Google; бесплатная работа не гарантируется. Звук выбранной вкладки во время перевода отправляется Google, история текста хранится локально 7 дней.

Если скачали архив исходников, загружайте папку `extension` внутри проекта. Подробности — в README.
