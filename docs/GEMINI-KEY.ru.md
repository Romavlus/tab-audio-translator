# Как получить и выбрать ключ Gemini

[English](GEMINI-KEY.md) | **Русский**

Расширению нужен **личный ключ Gemini API**. Пароль Google, OAuth client ID и JSON-файл сервисного аккаунта сюда не подходят. Модель уже выбрана расширением — в окне создания ключа выбирать её не нужно.

## Создание ключа

1. Откройте [Google AI Studio → API keys](https://aistudio.google.com/api-keys) и войдите в свой аккаунт.
2. Если это первый визит, ознакомьтесь с условиями Google. AI Studio может создать проект и ключ автоматически — доступный ключ можно скопировать.
3. Если нужен отдельный ключ, нажмите **Create API key**.
4. Выберите свой личный проект или создайте новый через предложенное окно. Если названия отличаются, ориентируйтесь на проект, которым управляете сами и чьи квоты собираетесь использовать.
5. Дайте ключу понятное имя, например **Tab Translator**. Имя не влияет на перевод.
6. Скопируйте созданный ключ. Новые ключи AI Studio по документации Google создаются с типом **Auth** по умолчанию.

Если существующий проект не виден, его можно добавить в AI Studio через **Dashboard → Projects → Import projects**, а затем создать ключ для него. Если нет прав на создание ключа, используйте свой проект либо обратитесь к его администратору.

## Подключение в расширении

1. Откройте «Перевод вкладки» → ⚙.
2. Вставьте ключ в поле **«Ключ API Gemini»**.
3. Нажмите **«Сохранить ключ»**, затем **«Проверить подключение»**.
4. После успешной проверки вернитесь назад и запустите перевод.

Ключ хранится в текущем профиле Chrome и не входит в файлы проекта. Не добавляйте его в README, скриншоты, Issues или коммиты.

## Квоты и ошибки

Создание ключа не гарантирует доступ к модели или бесплатное использование. Доступность зависит от проекта, региона, квот и тарифа Google. Если предлагается подключить оплату, сначала ознакомьтесь с её условиями и лимитами.

Подписка на пользовательское приложение Gemini не означает автоматически наличие доступа к Gemini API. Стоимость и квоты API проверяются отдельно в Google AI Studio.

При ошибке проверьте, что ключ относится к нужному проекту и имеет доступ к **Generative Language API / Gemini API**. Для этой версии используется модель `gemini-3.5-live-translate-preview`; если Google изменит её доступность, может потребоваться обновление расширения.

Источники: [официальная инструкция по ключам](https://ai.google.dev/gemini-api/docs/api-key), [Gemini Live Translation](https://ai.google.dev/gemini-api/docs/live-api/live-translate), [стоимость Gemini API](https://ai.google.dev/gemini-api/docs/pricing).
