# Установка и обновление

[English](INSTALLATION.md) | **Русский**

## Установка из готового ZIP

1. В репозитории откройте раздел Releases и скачайте `tab-audio-translator-v0.5.0.zip`.
2. Распакуйте архив в постоянную папку, например «Документы / Tab Audio Translator».
3. Откройте `chrome://extensions` в Google Chrome.
4. Включите «Режим разработчика» и нажмите «Загрузить распакованное расширение».
5. Выберите распакованную папку. В ней должны сразу находиться `manifest.json`, `popup.html` и другие файлы расширения.
6. Через меню пазла на панели Chrome найдите «Перевод вкладки» и закрепите иконку по желанию.

## Установка из исходников

1. Нажмите Code → Download ZIP на странице репозитория и распакуйте архив. Или клонируйте репозиторий через GitHub Desktop.
2. Откройте `chrome://extensions`, включите «Режим разработчика» и нажмите «Загрузить распакованное расширение».
3. Выберите **папку `extension` внутри проекта**. В корне проекта также есть README, LICENSE и package.json — этот корень выбирать не нужно.

Устанавливать Node.js или выполнять команды для этих способов не требуется.

## Подключение и запуск

1. Получите [ключ Gemini API](GEMINI-KEY.ru.md).
2. Откройте вкладку с видео, затем расширение → ⚙.
3. Вставьте ключ, сохраните его и проверьте подключение.
4. Вернитесь на главный экран, выберите язык и режим.
5. Нажмите «Начать перевод» и включите видео.

Ключ сохраняется в текущем профиле Chrome. В другой установленной копии расширения или другом профиле его нужно подключить отдельно.

## Обновление с сохранением настроек

1. Остановите текущий перевод.
2. Обновите файлы в **той же папке**, из которой расширение было установлено. Не удаляйте расширение в Chrome и не меняйте путь папки.
3. В `chrome://extensions` нажмите ⟳ на карточке расширения.
4. Откройте расширение заново и проверьте короткое видео.

Удаление расширения из Chrome удаляет его локальные данные. Для независимой копии выберите другую папку, но настройки и история будут отдельными. Две копии не стоит запускать одновременно на одном видео.

## Быстрая проверка установки

- В Chrome видна карточка «Перевод вкладки» версии 0.5.0, без сообщения об ошибке загрузки.
- Окно открывается; язык можно выбрать без выхода за границы поля.
- В настройках сохраняется ключ; проверка подключения проходит для вашего проекта Google.
- На коротком видео появляются озвучка и/или субтитры в выбранном режиме.
- Пауза и перемотка не продолжают воспроизводить старый фрагмент.
- После остановки текст доступен через «История ↗».
