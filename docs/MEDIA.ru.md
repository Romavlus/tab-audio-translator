# Скриншоты

[English](MEDIA.md) | **Русский**

Скриншоты создаются из настоящих HTML/CSS/JavaScript экранов расширения в отдельном браузере. Используются пример текста и имитация API: Google не получает запросов, настоящий ключ и история пользователя не используются. Скриншоты показывают интерфейс, а не качество или задержку перевода.

## Пересоздание

```sh
npm ci
npx playwright install chromium
npm run docs:screenshots
```

Английские скриншоты сохраняются в `docs/screenshots/`, русские — в `docs/ru/screenshots/`.

Проверьте результат: текст должен читаться, ключи и личные сведения отсутствовать, экран не обрезаться. Временные отчёты игнорируются через `.gitignore`.
