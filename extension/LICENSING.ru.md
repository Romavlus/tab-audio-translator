В текущем устанавливаемом пакете нет прежних заимствованных транспортных модулей и аудиопроцессоров. Они заменены новыми компонентами, реализованными по спецификациям Gemini Live API и Web Audio API. Заимствованные тесты также исключены из распространяемого исходного пакета и заменены собственными сценариями.
