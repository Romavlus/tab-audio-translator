# Extension data and privacy

**English** | [Русский](PRIVACY.ru.md)

Tab Audio Translator uses your own Gemini API key and connects directly to Google. The extension has no server of its own, analytics or advertising services.

While translation is running, Google receives audio from the selected tab. The extension receives translated speech and text in response. Google's data-handling terms depend on the API and plan you use: [Gemini API terms](https://ai.google.dev/gemini-api/terms).

Your API key and settings are stored locally in the Chrome profile without synchronization. The key is not sent to web pages. The subtitle interface receives only the text it needs to display.

Recognized original text and translations, together with dates, page titles and URLs, are stored locally for the last 7 days. Audio recordings are not archived. Open History to delete a single session or all records. Expired fragments are removed while the extension is running and after the next Chrome startup. Removing the extension removes its local data.
