The key stays in this Chrome profile. Google API quotas and pricing apply.

Which key should I choose?
  1. Open Google AI Studio → API keys and sign in.
  2. Choose Create API key. Use your personal project or create a new one. Give the key any name, for example Tab Translator.
  3. You need a Gemini API key, not an OAuth client or a service-account JSON file. New keys in AI Studio are Auth keys by default. The model is selected by the extension, not when creating the key.
  4. Copy the key, paste it here, save and check the connection. Access to the model depends on your project, region and API quotas; creating a key does not guarantee free usage.
